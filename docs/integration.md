# 網址查詢與其他網站串接

「TFDA仿單搜尋」可從網址帶入藥名、成分、藥證字號、健保碼或一般仿單文字。開啟網址後會自動搜尋，不需要再按按鈕。

## 標準參數

| 參數 | 對應欄位 | 規則 |
|---|---|---|
| `q` | 全部包含（AND） | 每個詞都要符合 |
| `any` | 任一包含（OR） | 至少一個詞符合 |
| `exclude` | 排除（NOT） | 含任一詞的章節排除 |

為了相容早期草稿，網站也會讀取 `all` 作為 `q`、`not` 作為 `exclude`；搜尋後網址會自動轉成標準參數。

每個詞須為 2–80 個字元，三個欄位合計最多 10 個詞。空白、半形／全形逗號與分號會分開不同詞。不可把病人姓名、病歷號、處方或其他病人資料放進網址。

## 例子

以下以尚未確定的正式首頁 `<TFDA網站網址>` 表示：

```text
<TFDA網站網址>?q=衛署藥製字第016162號
<TFDA網站網址>?q=A016162100
<TFDA網站網址>?q=腎功能不全
<TFDA網站網址>?q=懷孕%20噁心&exclude=動物試驗
<TFDA網站網址>?any=噁心%20嘔吐
```

產生網址時不要自己拼接特殊字元，應使用瀏覽器的 `URL` 與 `searchParams`：

```js
const target = new URL("<TFDA網站網址>");
target.searchParams.set("q", licenseNumber);
location.href = target.href;
```

## 與 ChemoDrugStable 的邊界

- 新網站目前已完成接收網址參數與自動搜尋。
- `chemodrugstable-query` 尚未被修改，既有網站、程式與 Git 歷史保持原樣。
- 新網站正式網址確定後，才在另一次明確授權下替 ChemoDrugStable 加入連結。
- 如果要讓新網站連回 ChemoDrugStable，也應等兩個正式網址確定後再設定，不先硬寫可能錯誤的網址。
- 兩邊只交換公開的查詢文字，不交換資料庫、登入狀態或病人資料；任一網站故障不應拖垮另一個。

正式上線後，以實際 Pages 網址重新跑 `?q=<完整藥證>`、健保碼及 AND／OR／NOT 深連結，才可把跨站整合標示為完成。
