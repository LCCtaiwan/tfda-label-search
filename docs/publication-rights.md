# 公開發布依據與邊界

核對日期：2026-09-15。這份文件是上線稽核紀錄，不是法律意見；若單位法務或資料提供機關另有明確要求，以新要求為準並更新 `config/publication-policy.json`。

## 可以公開使用的官方資料

政府資料開放授權條款第 1 版允許不限目的、時間與地域，以免授權金方式重製、編輯、改作、散布及公開傳輸；使用者必須清楚標示提供機關、資料名稱／版本及授權條款，且不得讓人誤認產品獲得機關推薦或認可。

本專案使用的兩個主要資料集都在政府資料開放平臺明確標示採用此條款：

- 衛生福利部食品藥物管理署「全部藥品許可證資料集」：https://data.gov.tw/dataset/9122
- 衛生福利部中央健康保險署「健保用藥品項查詢項目檔」：https://data.gov.tw/dataset/23715
- 政府資料開放授權條款第 1 版：https://data.gov.tw/license

TFDA 的網站資料開放宣告也說明，其網站資料與素材在得受著作權保護的範圍採相同條款發布，使用時應註明出處；機關標誌、專利、商標、另有特別聲明或涉及第三方權利的素材不在一般授權保證內：

- https://www.fda.gov.tw/Tc/opendata.aspx

## 結構化電子仿單的處理邊界

TFDA「藥品電子仿單交換格式」將介面定位為 Open Data。本專案依官方交換介面取得資料，但正式靜態網站只發布解析後的仿單純文字與可追溯欄位。

目前明確排除：

- API 內嵌圖片及 Base64 圖片。
- 整批 PDF 或圖片鏡像。
- TFDA、衛福部或健保署標誌。
- 另有特別聲明或無法確認第三方權利的素材。

使用者仍會看到官方原始頁面連結。若未來要把 PDF、圖片或標誌放進網站，必須重新確認權利，不能沿用目前的純文字放行結果。

## 第三方專案

來源專案：https://github.com/liangRXdev/TFDA-drug-info-search

使用者表示已取得原作者同意。目前正式專案只採用「獨立藥品網站、靜態快取及藥品／健保整合呈現」等需求概念，沒有複製該專案程式檔，因此 `publication-policy.json` 記為 `not_included`。

若日後要直接使用第三方程式，必須先：

1. 保存可公開交接的同意範圍，至少說明可修改、公開部署、再散布及署名方式。
2. 將同意紀錄與實際複製檔案列入 `publication-policy.json`。
3. 把狀態改為 `consent_verified`；缺少紀錄、署名或檔案清單時，上線前檢查會失敗。

## 自動上線檢查

`tools/pipeline/release_preflight.py` 會在候選網站建好後檢查：

- 授權依據核對日期未超過一年；過期後必須重新查證並更新日期。
- 官方授權證據仍完整。
- 結構化仿單仍限制為純文字，圖片、PDF 鏡像與機關標誌仍排除。
- 第三方程式狀態與同意紀錄相符。
- 網站頁尾看得到 TFDA、健保署、政府資料開放授權條款與非官方網站聲明。

檢查報告會存成 `publication-preflight.json`，與涵蓋率及 release manifest 一起交給主管審查。
